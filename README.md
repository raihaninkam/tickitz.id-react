# 🎬 Tickitz Movie Frontend

Frontend project for **Tickitz Movie** built with **React.js**.  
This project consumes the Tickitz Movie API and provides a modern, responsive user interface for browsing movies, booking tickets, and managing orders.

---

## 📦 Tech Stack

- **React.js (Vite or CRA)**
- **Redux Toolkit** (state management)
- **React Router** (routing)
- **Axios** (API requests)
- **TailwindCSS** (styling)

---

## 🌎 Environment Variables

Copy `.env.example` to `.env` and configure your API endpoint:

```env
VITE_API_URL=http://localhost:8080
```

🔧 Installation

Clone the project

git clone https://github.com/<your-username>/tickitz-frontend.git

Navigate to project directory

cd tickitz-frontend

Install dependencies

npm install

or

yarn install

Setup your environment

cp .env.example .env

Run the project

npm run dev

or

yarn dev
